## 通用框架（适用于 Tier 1/2/3）

### 开场：建立连接
```
您好，我是蹭饭图（Cengfan Map Studio）项目的维护者。

看到您在[平台]分享的[具体内容]，非常认同您对[教育/升学/设计]领域的洞察。
我们正在做一个开源的「毕业班去向地图」工具，希望能与您合作。
```

### 痛点共鸣
```
毕业季，班主任/班委要做「去向地图」，但面临：
• Excel 导出乱码、手动画 3-5 天
• 学生名单改了还要重画
• 想加校徽、字体、贴图但不会 PS

我们希望提供一个「3 分钟出图」的开源工具，解决这个痛点。
```

### 合作形式
```
我们提供：
1. 免费定制模板（您的品牌色 + Logo）
2. 数据支持（脱敏的真实案例数据）
3. 优先功能支持（您提出的需求优先开发）

您提供：
1. 1 篇深度笔记/视频（真实使用体验）
2. 1 条短视频/快闪（15-30 秒成果展示）
```

### 预期产出
```
预期产出：
• 笔记/视频曝光：您的粉丝数 × 5-10%
• GitHub Star：+200-500
• 真实案例：1-3 个（可进入「年度案例集」）
```

### 激励机制
```
作为感谢，我们提供：
• 您的署名出现在「案例墙」与「贡献者列表」
• 专属「KOL 定制模板」供您长期使用
• 毕业季「最佳班级地图」评选活动冠名权（可选）
```

### 结尾
```
期待您的回复！我们已准备好定制模板 Demo。
开源地址：github.com/Xhhemoing/cengfan-map-studio
联系方式： [微信/邮箱]
```

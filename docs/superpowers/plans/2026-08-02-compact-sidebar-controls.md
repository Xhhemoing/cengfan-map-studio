# 左右侧栏紧凑控件改造计划

## 目标

在正式 `/` 编辑器中统一左右侧栏和右侧 Inspector 的高频操作控件，减少重复按钮和无意义的占地，同时保留现有功能、回调、加载态、禁用态、确认流程和键盘可访问性。

## 范围

- 复用 `src/components/StudioUi.tsx` 作为控件入口，新增 `IconButton`、`CompactButton`、`SegmentedControl`、`ActionGroup`、`ToolbarButton`。
- 将列表行操作、层级操作、显示/隐藏、删除、复制、恢复等高频动作改为图标按钮，并保留 `aria-label`、`title` 和焦点样式。
- 将地图呈现方式、内容视图和素材高频操作改为紧凑分段控件或操作组。
- 将低频和高级设置继续收进 `details`，不移除任何设置项。
- 保持 `/prototype` 原型页面不变。

## 实施顺序

1. 共享控件与测试：扩展 `StudioUi`，先验证语义、键盘焦点和主要/次要变体。
2. 左侧名单与素材：收紧导入入口、筛选操作、行操作、素材库操作和资源包操作。
3. 左侧地图、内容和交付：统一分段控件、内容页签和交付动作层级。
4. 右侧 Inspector：统一标题区、对象操作和层级操作组；长表单保留高级折叠。
5. 全局设置和样式：复用同一套按钮 token，校验桌面/窄屏布局和深浅色主题。
6. 验证：运行相关 Vitest、TypeScript、Vite 构建、开发服务器检查和 Impeccable detector。

## 约束

- 不修改 `ProjectDocument`、导出文件格式和现有业务回调契约。
- 不删除原有操作，只改变呈现、分组或位置。
- 不覆盖工作区中已有的主题、流程导航、画布和设置改动。

# 左右栏信息架构（2026-08-26 定稿）

> **状态：已锁定，尚未实现。** 对标发布版本 **0.1.1** 的编辑器壳。实现排期为下一版（建议 semver **0.2.0**）。
> 产品方向来自 [2026-08-13 布局模板化设计](./2026-08-13-layout-template-refactor-design.md) 第三节，按 0.1.1 实装做了收口。
> 任务拆分见 [../plans/2026-08-26-left-right-rail-ia.md](../plans/2026-08-26-left-right-rail-ia.md)。

## 1. 为什么改

0.1.1 左栏是三个互斥页签：`AI 助手` / `本阶段` / `高级功能`。有名单时默认 AI，空名单时默认本阶段。规格要求左栏同时回答「进度 / 下一步 / AI」，右栏回答「选中了什么、能改什么」。

现状偏离：

- 「本阶段」与 AI 抢同一块高度，阶段总览经常看不见。
- 「高级功能」与顶栏项目菜单重复（协作、导入导出、去版式），还藏了元素大纲。
- 右栏同时扛阶段工具（地图表达、模板、交付检查、素材库）和对象检查器，窄栏里两套职责叠在一起。

## 2. 锁定决策（相对调研稿的优化）

调研时倾向「高级功能降为更多 / 并入项目菜单」。定稿改为 **删除「高级功能」页签**，而不是再加一个折叠入口：

| 今日高级功能里的项 | 定稿去向 |
|---|---|
| 管理协作与邀请 | 只留顶栏「项目」菜单（已有） |
| 项目菜单 / 导入导出 | 只留顶栏 |
| 前往版式 | 只留顶栏步骤条 |
| 数据诊断 | 「本阶段」总览卡点击（已有 `data-diagnostics`） |
| 元素查看 / 画布大纲 | 内容阶段的左栏总览动作（已有 `elements`），不要第三页签 |
| 排版问题列表 | 总览卡 `locate-layout` |
| 同步状态 · 名单条数 | 总览卡或顶栏已有保存反馈，不单开一组 |
| 渲染间隔 | 只读，不占左栏；改间隔仍走全局设置（legacy） |

其它收口：

1. **左栏改成分栏，不是第四个页签。** 上：AI（可折叠）；下：常驻 `StageOverviewPanel`。空名单时 AI 默认收起，总览占满；有名单后 AI 默认展开，总览仍可见。
2. **右栏只留「改对象 / 写出文件」。** 阶段说明一行可折叠。摘要、跳转、浏览类入口迁左，**不把检查器搬到左栏**。
3. **交付检查 vs 导出按钮：** 检查摘要（条数 + 跳转）在左；PNG 倍率、透明背景、工程包含资源、三枚写出按钮留右。左栏总览已有 `export-png` 仅用于「上次失败可重试」，不要在左栏再放三枚导出按钮。
4. **状态条 vs 本阶段：** `StatusStrip` 继续只播瞬时反馈（保存 / 导出 / 模板）。总览回答「这一步还缺什么」。两者不合并。
5. **地图栏撤销重做：** 顶栏已有 `historyActions`，`MapStyleRail` 里那一组删掉。
6. **`MapInspector` 默认展开高级项不得改。** 测试钉死 `keeps advanced controls open by default`。地图 / 内容阶段若要收纳，只在 **调用方** 传 `collapsible`，不改组件默认。
7. **版式 `TemplatePicker`：** 右栏里默认收进 `<details>`，避免和展示框细调抢首屏。
8. **名单「数据质量」双标题：** 外壳 `rightRailLabel` 与栏内 `PanelHeader` 不要再说同一句话。质量条数进左栏总览后，右栏标题改为选中学生 / 映射处理一类「能改什么」。
9. **不恢复「一键智能排版」。** 版式顶栏保持「刷新展示框位置」。
10. **不涨 `App.tsx` 行数闸门**（现 923）。壳组合继续在 `StudioAssistantRail`、`StageLayoutScreen`、各 `*Rail`。不改 `ProjectDocument`，不移动 App 顶层 hooks。

## 3. 栏契约

### 3.1 左栏（默认 280px，可拖 240–380）

固定两区，独立滚动：

```
┌ AI 助手（可折叠；docked AgentAssistant）
├────────────────
└ 本阶段（StageOverviewPanel，始终挂载）
```

- 桌面：两区上下同屏。
- 窄屏抽屉：同一结构；入口文案改为「AI 与本阶段」（去掉「高级功能」）。
- 总览卡点击只做跳转 / 定位 / 打开已有弹层，不在左栏挂 `onPatch`。

### 3.2 右栏（默认 240px，可拖 220–420）

- 顶上一句阶段说明（目标 → 当前动作 → 结果），默认折叠。
- 其下只有该阶段的编辑控件或写出控件。
- 未选中对象：一句引导（如「点击画布上的省份开始编辑」），不要空白检查器。

各阶段右栏标题（将改写 `STAGE_METADATA.rightRailLabel`，并改 `App.shell-layout.test.tsx` 锚点）：

| 阶段 | 0.1.1 标题 | 0.2 标题 |
|---|---|---|
| 名单 | 数据质量 | 名单记录 |
| 地图 | 地图对象属性 | 地图对象属性 |
| 版式 | 版式与展示框样式 | 展示框样式 |
| 内容 | 内容对象属性 | 内容对象属性 |
| 交付 | 导出与检查 | 导出 |

### 3.3 搬迁表

| 能力 | 0.1.1 | 0.2 | 说明 |
|---|---|---|---|
| 名单质量条数 / 告警跳转 | 右 `DataUploadRail` + 左总览 | **主入口左总览**；右栏保留「点选后改这一行 / 省份覆盖」 | 不删 `DataQualityPanel`，改主入口 |
| 地图表达（省份/城市/…） | 右 `MapStyleRail` | **左**（当前阶段卡或分段控件） | 这是阶段决定，不是对象属性 |
| 地图 / 省检查器 | 右 | **右** | 必留 |
| 地图栏内撤销重做 | 右 | **删**（用顶栏） | |
| 版式模板列表 | 右 `TemplatePicker` 展开 | **左**给入口；右可保留折叠副本 | 避免两处都能 apply 时状态打架：以左为切换、右为确认也可，实现时只留一处 `onApplyTemplate` |
| 展示框 4 套 + `CardsInspector` | 右两套控件 | **右收成一处** | 下拉与四格不要重复同一字段 |
| 内容对象检查器 | 右 | **右** | |
| 内容「整体模板与交换」 | 右 `<details>` | 可留右折叠，或入口在左 | 0.1.1 刚放到内容右栏，不要藏回全局设置 |
| 素材库浏览 | 右，画布态默认展开 | **左**大纲/浏览；右在选中素材时仍编辑该实例 | |

| 导出倍率 / 透明 / 含资源 / 三按钮 | 右 | **右** | 必留 |
| 顶栏导出 PNG / 导出工程弹层 | 顶栏 | 顶栏不动 | 与右栏按钮并存可以，文案都要走同一 `posterExport` 忙闲 |

## 4. 明确不做

- 不实现于 0.1.1；本文件只锁契约。
- 不把 Map / Cards / 文字 / 素材检查器挪到左栏。
- 不改工程包 / 协作协议 / 导入表头语义。
- 不接线 `print-bleed`、不合并 `useStudioPreferences`。
- 不把支付、套餐、遥测加进任何栏。
- 不把左栏默认宽度抬过 380（`editor-layout.ts` 上限仍在）。

## 5. 回滚

实现 PR **不改持久化 schema**。回滚 = 还原该 PR 的提交。IndexedDB 工程、社区模板、导出文件名规则与 0.1.1 兼容。

## 6. 验收（实现完成后）

- 有名单的项目：不点页签也能同时看到 AI 输入框与至少一张本阶段卡。
- 空名单：总览第一张仍是「还没有名单」，AI 收起但可展开。
- 交付阶段：左栏能看到检查条数；不点右栏也能知道「能否导出」；写出仍在右栏或顶栏。
- 读屏：左栏两个 `region`（AI / 本阶段），不再是三个 `tab`。
- `App.tsx` 行数不升；`StudioAssistantRail` 若涨行则拆文件，不抬无关白名单。

# 数据导入与编辑浮层规范

## 目标

规范全局数据工作台中的学生数据导入入口，使用户可以下载统一的 XLSX 模板，导入列名不固定的表格，并在导入前看到系统识别出的字段和代表性数据。同时修复表格行内编辑时城市、省份备选框被表格滚动容器裁剪的问题。

## 范围

### 规范字段

导入模板和智能识别统一面向现有 `Student` 模型的四个字段：

| 规范字段 | 必填 | 模板列名 | 代表数据 |
| --- | --- | --- | --- |
| `name` | 是 | 学生姓名 | 林舟 |
| `university` | 是 | 录取院校 | 北京大学 |
| `city` | 是 | 城市 | 北京市 |
| `locationScope` | 否 | 去向类型 | 中国去向 / 海外去向 |

模板下载生成两个工作表：`学生数据` 提供规范列和空白填写行，`填写说明` 说明列含义和必填规则。示例数据只出现在说明页，避免用户忘记删除示例后产生误导导入。

### 智能识别

- 扫描前 8 个非空行，选择规范字段命中数最多且至少命中 2 个字段的行作为表头。
- 表头匹配前去除空格、下划线、短横线、括号并统一大小写。
- 支持现有中文别名和常见英文别名，包括 `姓名`、`学生姓名`、`录取学校`、`就读院校`、`所在城市`、`destination city` 等。
- `name`、`university`、`city` 三个字段均命中时，按识别后的列读取记录；`locationScope` 命中时识别 `海外`/`international` 为海外去向，其余非空值按中国去向处理。
- 识别结果返回表头行号、规范字段到原始列名的映射，以及每个已识别列最多两个非空样例值。
- 表头不完整时仍保留现有文本兜底解析，不破坏无表头的 CSV/Excel 导入。

### 界面行为

- Excel 导入入口旁提供“下载 XLSX 模板”按钮，下载名固定为 `蹭饭图-学生数据导入模板.xlsx`。
- 成功识别 Excel 后，在候选确认区前展示“表头识别”摘要：原始列名、识别字段和代表数据；未识别列显示为“未使用”，缺少必填字段时显示警告。
- 文本、OCR、AI 导入继续使用现有候选确认流程，不显示虚假的表头识别结果。
- 导入确认、追加/替换、现有 `ProjectDocument` 事务和数据质量计算不改变。

### 编辑浮层

- `SearchCombobox` 增加可选 portal 渲染模式；普通新增表单保持现有相对定位。
- 表格编辑中的城市、省份备选框使用 portal 挂载到 `document.body`，以输入框 `getBoundingClientRect()` 为基准使用 fixed 定位。
- 浮层在滚动、窗口变化和键盘操作时保持可用，Esc、失焦、选项点击行为保持现有约定。
- portal 浮层的层级高于数据表头和滚动容器，且不通过修改全局滚动策略影响导入区或画布。

## 不做的事情

- 不新增第二套学生数据状态或持久化格式。
- 不引入后端或外部 AI 服务来判断表头。
- 不把任意未识别列自动写入 `Student`，只在识别摘要中展示为未使用。
- 不改动导出的海报视觉和现有非表格场景的下拉控件。

## 验收标准

1. 点击模板按钮能触发一个有效 XLSX 下载，首个工作表含四个规范列，说明页含必填提示和示例。
2. 表头位于前 8 个非空行中的任意位置、列顺序打乱、使用常见别名时，都能得到正确字段映射和候选记录。
3. 识别摘要能同时呈现原始表头、规范字段和代表数据；缺少必填列时有明确警告并仍可走兜底解析。
4. 表格编辑时城市/省份选项不会被 `td` 或 `.data-table-wrap` 裁剪，现有键盘交互测试继续通过。
5. 聚焦 Vitest、类型检查、构建、Lint 和浏览器手动验证均有新鲜输出记录。

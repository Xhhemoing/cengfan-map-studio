# 前端编辑器重构设计规格

## 目标

将主编辑器重构为轻便、易上手、性能稳定的地图海报工作台，保留现有工程数据模型、导入导出、撤销重做、素材、字体、AI 与协作能力。默认支持亮色和暗色两种界面主题，主题只影响工具界面，不改写海报成图颜色。

## 界面结构

主编辑器采用单行顶栏和三栏工作区：

```text
项目菜单 | 1 名单  2 地图  3 版式  4 内容  5 素材  6 交付 | 历史/缩放/主题/导出
┌────── 当前任务 ──────┬──────────── 海报画布 ────────────┬──── 当前对象 ────┐
│ 任务级动作与至多三组设置 │ SVG 成图 + 交互覆盖层              │ 选中对象属性     │
└──────────────────────┴──────────────────────────────┴──────────────────┘
```

左右栏分别以约 168px 与 174px 为桌面基线，中央区域使用剩余宽度。两侧内容必须允许折叠；中屏右栏变为按需抽屉；小屏在“设置/画布”之间切换，保留名单修改、换素材、轻量调整和导出。

左侧栏只显示当前步骤的任务内容，不再放置第二套流程导航；流程切换唯一入口是顶栏的六步步骤栏。

顶栏只放项目管理、步骤导航、撤销/重做、缩放、主题切换、AI、预览和导出。项目菜单负责新建、打开最近工程、保存到本机、导入/导出工程包、模板复用和协作入口，不复制 PNG/SVG 导出按钮。

## 画布架构

`ProjectDocument` 仍是唯一持久化数据源。渲染前由纯函数把工程数据派生为 `RenderScene`；`PosterCanvas` 负责 SVG 成图层，新增 `CanvasInteractionOverlay` 负责选框、控制柄、辅助线、悬停和拖拽预览。拖拽期间只更新 overlay 的临时位置，并使用 `requestAnimationFrame` 合帧；松手后通过现有事务接口提交一次位置变更，进入撤销历史。

地图投影、卡片布局、文本排版、连接线和导出逻辑继续使用现有纯函数。命中测试优先使用场景对象的稳定 id 和几何 bounds，避免从 React DOM 结构反推对象。成图 SVG 与交互 overlay 分离后，指针移动不再触发 App 全局工程状态更新。

## 主题系统

新增 `ThemeMode = "light" | "dark"` 与 `"system"` 偏好解析。用户选择持久化在独立 localStorage key，首次使用跟随 `prefers-color-scheme`。CSS 通过语义 token 控制背景、面板、文本、边界、主操作、警告和焦点；海报内部颜色继续来自工程模板和用户设置。主题切换必须无页面重载，且不改变撤销历史、画布缩放或工程数据。

## 工作区迁移

六个工作区保留现有功能，按“任务面板 + 当前对象检查器”分工：名单提供导入、问题摘要和全屏管理；地图提供表达方式和省份快捷动作；版式提供模板、规格、卡片预设和智能排版；内容提供标题/备注/嘉宾大纲；素材提供上下文筛选和应用；交付提供健康检查、导出和工程管理。旧的全局设置屏幕暂时保留底层组件，但不作为主导航入口。

## 验收标准

- 亮色与暗色切换不刷新页面，工具界面文本和控件保持可读；
- 顶栏只有一行，步骤和项目入口在桌面宽度可见；
- 左右栏都存在且不挤压中央画布，窄屏下可以收起；
- 拖动画布对象时不会每个 pointermove 写入工程历史；
- 原有工程导入、工程包、PNG/SVG 导出、撤销重做和协作测试继续通过；
- 320、768、1024、1440px 下无页面级横向溢出。

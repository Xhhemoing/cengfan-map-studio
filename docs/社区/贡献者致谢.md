# 贡献者致谢规则

蹭饭地图工作室的贡献不只有代码。本文规定谁会被致谢、以什么方式、写在哪里。规则先行：在第一位外部贡献者出现之前，本文只放规则，不放名单。

## 一、同等致谢原则

以下贡献同等致谢，不分高低（与 [CONTRIBUTING.md](../../CONTRIBUTING.md)「什么样的贡献都算」一致）：

- **文档**：用户指南、开发者文档、案例说明、错别字与表述修正。
- **模板**：投稿社区模板文件（`.cengfan-template.json`）、案例模板配置与制作步骤。
- **脱敏数据**：虚构示例名单、脱敏截图、测试用例数据。
- **答疑**：在 Issue / 用户群里帮人复现问题、解答导入与出图问题。
- **代码**：功能、修复、测试、性能、UI。

使用后留下一句真实的劝退点（导入 / 布局 / 导出哪里用不了），同样算贡献。

## 二、致谢载体

- **[CHANGELOG.md](../../CHANGELOG.md)**：条目点名意见提出者与实现者，尽量附 Issue / PR 链接留痕。
- **本文名录**：首次贡献合入后按时间顺序加入（见文末）。
- **社区模板署名**：见下节。

## 三、社区模板署名（可选）

- 社区模板文件格式含可选的 `author` 字段（不超过 30 字符，仅填昵称）。
- 是否署名由作者自行决定，留空即匿名投稿。
- 他人再分发已署名的模板时，不得移除原作者署名。
- 模板随仓库按 AGPL-3.0-only 分发；投稿即确认素材已获授权、不含真实学生名单。

## 四、命名与隐私规则

- 一律使用 GitHub ID 或本人自选昵称，不写真实姓名。
- 不出现「学校全名 + 个人」的组合。
- 从 Issue、问卷或群消息转述意见时，不得引用其中的真实学生名单内容。
- 本人可随时要求更名、匿名化或移除自己的致谢条目。

## 五、明确不做

- **不设 VIP、会员、专属付费模板**等任何付费激励——与 AGPL-3.0-only 及 [docs/开源与收费边界.md](../开源与收费边界.md) 冲突，社区模板永远免费交换。
- **不虚构贡献者名单**：没有贡献就不放名字，不为「显得热闹」编造条目。
- **不承诺仓库之外无法兑现的回报**（实体物品、线下服务等）；致谢的载体只有本仓库内的文件与链接。

## 名录

暂无外部贡献者。第一条致谢将同时出现在这里与 [CHANGELOG.md](../../CHANGELOG.md)。

# 全屏全局设置实施计划

## 目标

将画布、地图展示框、数据板块和辅助板块等项目级设置从编辑器左右侧栏中迁出，通过顶部固定入口进入独立、占满视口的设置界面。全屏设置模式不渲染原编辑器顶栏、左侧工作区、画布工具栏或右侧属性栏，修改继续使用当前项目事务与撤销/重做机制。

## 已批准交互

- 编辑器顶部提供“全局设置”入口。
- 点击后切换到独立的全屏设置界面，而不是侧栏、弹窗或编辑器内三栏布局。
- 设置页提供“画布设置 / 地图展示框 / 数据板块 / 辅助板块”四个分区。
- 顶部提供返回编辑器、撤销和重做；返回时恢复原编辑器状态。
- 设置实时写入当前工程，不新增第二套保存模型。
- 单个省份、文本、素材和具体人员内容继续在普通编辑器编辑。

## 实施切片

### 1. 全屏模式壳层

- 先在 `src/App.test.tsx` 写入口、隐藏普通编辑器、返回恢复的失败测试。
- 新增独立 `GlobalSettingsScreen` 组件。
- 在 `App` 中增加全屏模式状态并复用现有撤销/重做处理器。

验收：设置模式下 `.topbar`、`.workspace`、左右栏均不渲染。

### 2. 迁移项目级控件

- 画布设置复用 `CanvasInspector`。
- 地图展示框复用 `MapInspector`。
- 数据板块复用完整的 `CardsInspector`，保留一键智能排版。
- 辅助板块只暴露嘉宾板块的显示、位置、尺寸和整体外观，不迁入人员内容编辑。
- 从左侧设计工具移除重复的“卡片”入口；右侧全局对象选择改为指向全局设置的引导入口。

验收：四个分区修改均进入当前项目历史，撤销/重做有效。

### 3. 全屏布局与响应式

- 独立页使用全视口纵向结构：固定页头、分区标签、可滚动表单内容、状态栏。
- 宽屏控件按多列分组；窄屏变为单列，标签可横向滚动，文本和控件无裁切。
- 分区切换使用可访问标签语义，入口和返回按钮有明确名称与焦点样式。

验收：桌面、平板和手机宽度均无水平溢出。

### 4. 验证与审查

- 运行新增目标测试。
- 串行运行 `npm run test`、`npm run lint`、`npm run build`。
- 使用真实 Chromium 检查入口、切换、返回、四分区、溢出和控制台错误。
- 检查实际 diff，确认未覆盖脏工作区中的无关改动。

## 风险控制

- `App.tsx` 已很大：新界面放在独立组件中，只在 App 中加入最小状态与回调接线。
- 工作区已有大量未提交改动：只按明确 hunk 修改本任务文件，不重置、不整体暂存、不提交。
- 现有控件存在重复：以 `CardsInspector` 为完整数据板块来源，避免继续维护两份参数界面。

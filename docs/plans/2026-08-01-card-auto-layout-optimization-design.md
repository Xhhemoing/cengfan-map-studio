# 自动数据框排布优化设计

日期：2026-08-01

## 目标

1. 禁排范围使用当前渲染状态下的真实可见障碍：投影后的省份 AABB、自定义地图图像区域、南海插图和固定文本/嘉宾区。
2. 地图内容并集外框只用于计算中心、方位和参考轨道，不再作为禁排矩形；数据框可以使用外框内部未被真实障碍占用的空白。
3. 数据框中心尽量接近对应省份锚点。锚点沿用现有语义：优先 GeoJSON 行政中心（省会/行政中心），无有效数据时退化到省份几何中心。
4. 使用与 SVG 渲染完全相同的连接线几何，优先选择不与既有连接线相交的候选。
5. 在锚点方位允许及单侧容量不足时，将数据框稳定分流到上、右、下、左四侧。

## 约束优先级

硬约束：

- 数据框完整位于安全边距内。
- 数据框之间不重叠，并保留配置间距。
- 数据框不与实际可见障碍重叠。
- 输入数据框不丢失，输出稳定且有确定性。

软目标（按优先级）：

1. 减少连接线交叉。
2. 减少连接线穿过其他数据框。
3. 缩短数据框中心到对应锚点的距离。
4. 保持锚点的自然方位，避免无意义地跨越地图。
5. 平衡四侧负载，在局部拥挤时优先使用其他可用侧。

## 算法

1. 根据画布边界、锚点投影、地图内容参考边界和每个真实障碍的边缘生成有限候选坐标。
2. 过滤越界、碰撞实际障碍的候选；每侧保留按静态距离和自然方位排序的有限候选，控制搜索规模。
3. 按锚点相对地图中心的极角稳定排序，同锚点按 id 排序。
4. 贪心放置时过滤已放置数据框碰撞，并使用真实连接线几何计算新增交叉数；交叉数优先于距离。
5. 做有限轮局部改进，逐个尝试其他候选，降低全局交叉、中心距离和侧负载成本。
6. 当候选搜索无法满足硬约束时，退回现有确定性自由空间重排；物理饱和时保留可见回退状态。

## 兼容性

- 不修改项目文档数据结构和已有手动位置。
- `connectorStyle` 与 `connectorWidth` 由渲染端传入求解器，兼容旧 API 包装层。
- `grid` 与 `right-stack` 保留明确模式语义；优化重点用于默认 `quadrant` 和 `radial` 自动排布。
- 手动拖拽使用同一实际障碍集合，存在 `occupiedAreas` 时不再额外禁止整个地图并集外框。

## 验证

- 单元测试证明数据框可进入地图并集外框内但未占省份像素的空白区。
- 单元测试证明四方锚点至少分布到四侧。
- 单元测试使用 `buildConnectorGeometry` 验证可行场景下连接线不交叉。
- 单元测试比较中心距离，证明选择更近的无交叉候选。
- 运行布局测试、画布集成测试、浏览器截图/几何检查，再运行全量 test、lint、build。

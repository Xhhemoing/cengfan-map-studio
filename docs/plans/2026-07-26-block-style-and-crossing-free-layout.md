# 板块样式与无交叉智能排版实施计划

## 目标

修复板块样式连续修改被旧项目状态覆盖的问题，并用布局器与渲染器共享的连接线几何实现确定性的智能排版：在规范候选空间存在可行解时，卡片不越界、不重叠、不压省份内容，实际显示连接线不交叉。

## 保证边界

- 无交叉保证限定于布局器生成的有限、确定性候选空间。
- `solved` 必须满足所有硬约束。
- 搜索预算耗尽不能报告为无解。
- 物理空间不足时不得抛错、越界、重叠或静默隐藏；依次采用紧凑候选和最少冲突降级，并暴露结果状态。
- 手动位置是首选而非破坏全局约束的绝对硬约束；拖动预览和提交均重新计算端口与连接线。

## 任务 1：修复板块样式状态事务

1. 在 `src/App.test.tsx` 写失败测试：同步连续修改两个卡片字段后，控件状态与 SVG 同时保留两次修改。
2. 确认测试因闭包旧 `project` 覆盖而失败。
3. 将 `patchScene` 和受影响的卡片移动提交改为 `commitProjectTransaction`，始终在最新状态上应用事务。
4. 添加 AI 预览清除、自动保存恢复的目标回归测试。
5. 运行 `src/App.test.tsx`。

## 任务 2：建立共享连接线几何

1. 新建 `src/lib/connector-geometry.test.ts`，先测试四边端口、直线、折线、曲线展开及可靠相交判定。
2. 新建 `src/lib/connector-geometry.ts`：唯一构造 `pathData`、展平线段和安全包络的纯函数。
3. 修改 `PosterCanvas` 直接使用共享 `pathData`，删除本地路径公式。
4. 运行几何与画布目标测试。

## 任务 3：替换为确定性约束布局

1. 扩展 `destination-layout.test.ts`，先加入失败测试：
   - 实际连接线零交叉；
   - 密集同侧卡片分流到多轨；
   - 相同输入输出逐值一致；
   - 手动首选位置仍满足全局约束；
   - 不可行输入返回显式降级而非抛错。
2. 生成规范候选：安全边界、地图四侧轨道、省份障碍边缘和手动首选位置。
3. 每个候选绑定卡片矩形、端口、路由、共享连接线几何与稳定成本。
4. 预计算候选冲突图：卡片冲突、连接线互交、连接线穿卡片。
5. 用 MRV、稳定排序和前向检查执行确定性回溯；以搜索节点预算防止界面冻结。
6. 无完整解时返回保持卡片硬约束的最少交叉最佳已知解，并提供 `crossing-fallback` 状态。
7. 运行布局压力测试。

## 任务 4：画布、拖拽和样式联动

1. `PosterCanvas` 将线型、线宽和手动位置传入布局器。
2. 样式几何字段变化自动重新求解；一键排版清空手动首选位置。
3. 手动拖动只预览全局合法位置，提交时使用重新计算后的端口和连接线。
4. 增加画布 DOM 测试，断言 SVG 路径与布局器共享几何一致。

## 任务 5：验证

1. 目标测试：App、connector geometry、destination layout、PosterCanvas。
2. 全量 `npm run test`。
3. `npm run lint`。
4. `npm run build`。
5. `git diff --check`。
6. 核验 `http://127.0.0.1:8787` 提供最新 bundle；浏览器能力可用时执行交互与截图验证，否则明确记录环境限制。

# 右侧栏紧凑布局与全局姓名表达设置

日期：2026-08-01
状态：实施中

## 目标

1. 右侧检查器在有限高度内保持可滚动，减少重复入口、间距和常驻低频内容，避免内容视觉上撑出栏体。
2. 将卡片表达式（标题、城市、名单行）与姓名格式从右侧卡片检查器迁移到全局设置的“高级设置”分区。
3. 支持姓名展示预设：完整姓名、全名首字母、姓*某、姓+名首字母；继续支持受限自定义模板和复姓识别。
4. 保持现有 `ProjectDocument.cards` 数据兼容，不引入第二套持久化状态；全局设置直接 patch 当前 cards 配置。

## 实现边界

- `CardsInspector` 的主面板只保留布局、视觉、位置和连接线等高频配置；其 `advancedControls` 不再渲染在右侧栏。
- `GlobalSettingsScreen` 增加 `advanced` 分区，集中渲染卡片表达式与姓名格式设置，并使用同一套 patch/历史事务。
- `name-format.ts` 只通过模板占位符实现格式化，禁止使用 `crypto.randomUUID()` 或其他不相关改动。
- 右侧栏 CSS 使用更小的内边距、间距和紧凑控件高度；检查器本身继续在栏内滚动，不改变窄屏隐藏行为。

## 验收

- 右侧栏的 `.inspector` 不产生页面级横向溢出，长内容在栏内滚动。
- 全局设置可见“高级设置”分区，能编辑 `{name}`、`{university}` 等表达式与姓名格式，并实时反映到海报。
- 右侧卡片面板不再显示姓名格式和卡片表达式控件。
- 目标 Vitest、lint、build 串行通过。

# 毕业季 Checklist（3 版）

## 班主任版（开学典礼/毕业典礼前 2 周）

- [ ] 收集最终学生名单（Excel/CSV 格式）
- [ ] 确认去向字段（省份/城市/学校/公司）
- [ ] 下载蹭饭图最新版本（GitHub Releases）
- [ ] 导入名单 → 检查匹配率（>95%）
- [ ] 选择卡片模板（紧凑/宽松/极简）
- [ ] 上传校徽 + 班级字体
- [ ] 手动微调重叠卡片（<10 个）
- [ ] 导出高清 PNG（用于毕业墙）
- [ ] 导出 PDF（用于打印）
- [ ] 导出项目包（.cengfan，备份用）
- [ ] 分享到班级群/家长群
- [ ] 收集反馈 → 优化模板

---

## 班委版（收到名单后 2 天内出初稿）

- [ ] 确认名单格式（姓名、去向、省份）
- [ ] 安装蹭饭图（npm install + npm run dev）
- [ ] 导入名单 → 自动布局
- [ ] 上传素材（校徽、贴图、字体）
- [ ] 调整颜色与样式
- [ ] 导出 3 种风格供投票
- [ ] 收集投票结果
- [ ] 最终版导出 + 分享
- [ ] 归档项目包（下次复用）

---

## 学生/家长版（返校日/毕业 N 年后更新）

- [ ] 下载原项目包（.cengfan）
- [ ] 导入蹭饭图
- [ ] 更新个人去向（真实数据）
- [ ] 导出更新版地图
- [ ] 分享到朋友圈/校友群
- [ ] 投稿「年度案例集」（可选）

---

**提示**：所有 checklist 均需脱敏后操作，禁止在群内分享真实姓名 + 具体去向。

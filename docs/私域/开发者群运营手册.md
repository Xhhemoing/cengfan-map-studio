# 蹭饭图开发者群运营手册

与用户群拆开。这里只服务 **能跑仓库或愿意提 Issue 的人**。

**群名**：蹭饭图开发者（意见 / PR）  
**目标**：8 周内 20 人，其中每周至少 5 人说过一句话。

---

## 置顶公告

```
【开发者群】
1. 使用/导入问题请去用户群，这里不教 Excel。
2. 提意见优先用 GitHub Issue 模板，群里可以先吵方向。
3. 认领 good first issue 请在 Issue 下留言「我来做」。
4. 禁止真实学生名单。
5. 维护者 48 小时内回复 Issue；群消息非紧急可不秒回。

仓库：https://github.com/Xhhemoing/cengfan-map-studio
贡献：CONTRIBUTING.md
本周议题：见群公告第二条（每周一更新一个具体问题）
```

---

## 节奏

| 日 | 动作 |
|----|------|
| 一 | 公布本周一个具体问题（导入 / 布局 / Demo 范围三选一） |
| 三 | 点名未回复的 Issue，问是否还做 |
| 五 | Changelog（与 `每周推送模板.md` 开发者版相同） |

不要每天发招募。连续两周没人说话时，发一条 V2EX/掘金同步进群的短进展，而不是催「来 Star」。

---

## 激励

- 文档/模板/第一次 PR：Changelog 点名
- 连续两周有效意见：README 致谢（本人同意）
- 不要发空头「证书 PDF」除非真的做了文件

---

## 和用户群的边界

| 消息 | 去向 |
|------|------|
| 导入失败截图 | 用户群 |
| 「表头识别策略该不该更激进」 | 开发者群 + Issue |
| 「能不能帮我们班做一张」 | 用户群，不在开发者群接私活广告 |

# 需求收集表（腾讯问卷可照抄）

每周三在用户群发一次链接。周日把新回复转录为 GitHub Issue（`user-feedback`）。

## 题目

1. 身份（单选）：班主任 / 年级组长 / 班委 / 学生 / 家长 / 开发者 / 其他
2. 这次想做的图（单选）：开学班级图 / 毕业去向墙 / 校庆或同学会 / 社团活动 / 还没做，先看看
3. 卡在哪一步（单选）：打不开工具 / 导入名单 / 卡片重叠或太挤 / 样式与校徽 / 导出与打印 / 不知道怎么分享给同事 / 其他
4. 一句话建议（填空，必填）
5. 没有这个功能时，你现在怎么凑合？（填空）
6. 是否允许把建议写进公开 Changelog（署名可用昵称）（单选：允许 / 匿名允许 / 不允许）
7. 方便回访的微信号（选填）

## 群里预告文案

```
本周需求收集（3 分钟）：
请说「哪一步最劝退」，比说「希望有 AI」更有用。
链接：<腾讯问卷>
周日会把大家的意见转到 GitHub，并在群里公布哪些做、哪些暂缓。
```

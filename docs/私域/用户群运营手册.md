# 蹭饭图用户群运营手册

## 一、群定位与目标

**群名**：蹭饭图用户交流群（微信/QQ）  
**目标人数**：3 个月内 300 人，6 个月内 1000 人  
**核心价值**：技术支持、案例分享、需求收集、UGC 征集

---

## 二、群规则（置顶公告）

```
【群规则】
1. 禁止广告、拉人、发无关链接
2. 提问请提供：操作系统、浏览器、错误截图
3. 分享案例请脱敏（姓名缩写、去向模糊化）
4. 禁止讨论「升学率」「就业率」等敏感数据
5. 禁止传播违法或侵权内容

违反者将被移出群聊。
```

---

## 三、日常运营节奏

### 周一：新功能/模板推送
```
主题：本周新模板上线
内容：
• 3 种新卡片模板（极简/卡通/正式）
• 1 个真实案例（脱敏）
• 1 个「小技巧」：如何快速绑定校徽
```

### 周三：需求收集
```
主题：你希望蹭饭图支持什么功能？
内容：
• 投票：世界地图 / 国际部模板 / 导出 Word
• 开放讨论：最想解决的痛点
```

### 周五：UGC 征集
```
主题：本周优秀案例展示
内容：
• 展示 2-3 个高质量案例
• 征集：你的毕业地图故事
• 奖励：优秀作品进入「年度案例集」
```

### 周日：复盘与答疑
```
主题：本周问题汇总
内容：
• 常见问题解答（FAQ）
• 下周计划预告
• 开放答疑（2 小时）
```

## 四、种子用户培养

### Tier 1：核心贡献者（10 人）
**特征**：活跃度高、贡献模板/代码/案例  
**激励**：
- 专属「核心贡献者」角色
- 每月专属模板定制
- 年度「最佳贡献者」评选

### Tier 2：活跃用户（50 人）
**特征**：每周发言、分享案例、反馈 Bug  
**激励**：
- 优先功能支持
- 案例曝光
- 开源贡献者证书

### Tier 3：普通用户（剩余）
**特征**：偶尔提问、下载模板  
**激励**：
- 基础技术支持
- 定期模板推送

## 五、危机处理

### 场景 1：用户反馈 Bug
**流程**：
1. 立即回复：「已记录，感谢反馈！」
2. 24 小时内确认是否复现
3. 复现后在群内更新进度
4. 修复后 @用户 并感谢

### 场景 2：用户分享敏感数据
**流程**：
1. 立即删除消息
2. 私信提醒：「请脱敏后重新分享」
3. 群内公告：「请注意数据脱敏」

### 场景 3：用户抱怨功能缺失
**流程**：
1. 共情：「理解您的需求」
2. 说明：「已记录到需求池，优先级排序中」
3. 提供 workaround：「目前可通过 XXX 实现」
4. 跟进：「预计下版本支持」

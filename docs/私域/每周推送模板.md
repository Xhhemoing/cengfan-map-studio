# 每周推送模板

用户群与开发者群 **不要共用同一段话**。

---

## 用户群 · 周一

```
【本周能直接用】
• 示例 CSV 在群文件，表头是：姓名、去向、省份
• 一个小技巧：<本周一条，例如 重叠卡片先点智能布局再手拖两张>
• 需要帮助：带系统 + 浏览器 + 打码截图
```

## 用户群 · 周三（需求）

直接用 `需求收集表.md` 里的预告文案。

## 用户群 · 周五（作品）

```
【本周出图】
• <1–2 个脱敏成品，或「还在等第一张开学图」>
• 投稿格式见群文件「案例投稿模板」
• 不要发未打码名单
```

## 开发者群 · 周五（Changelog）

```
【本周意见 → 改动】
收到：N
已改：…
暂缓：…（原因）
求拍砖：<一个具体问题>
Issue：https://github.com/Xhhemoing/cengfan-map-studio/issues
感谢：@…
```

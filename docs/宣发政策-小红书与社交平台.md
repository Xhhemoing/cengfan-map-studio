> 目标：让「毕业班去向地图」成为毕业季标配内容，3 个月内积累 5000+ 真实用户与 200+ 案例作品。

## 二、核心人群画像

### 1. 决策者（班主任、年级组长）
- 痛点：毕业季要做「去向地图」但 Excel/PPT 太丑、太慢
- 场景：开学典礼、毕业墙、班级公众号推文
- 决策因素：一键出图、学生名单直导、可导出高清图

### 2. 执行者（班委、设计组、学生会）
- 痛点：手动画地图、调样式、排版耗时 3-5 天
- 场景：收到名单后 2 天内出初稿
- 决策因素：导入 Excel 即出图、支持二次编辑、导出不失真

### 3. 受益者（毕业生、家长）
- 痛点：想知道「我们班都去了哪里」，有纪念意义
- 场景：毕业典礼、返校日、朋友圈分享
- 决策因素：美观、真实、能导出发朋友圈

### 4. 传播者（教育博主、升学咨询、设计博主）
- 痛点：需要真实案例、工具推荐
- 场景：毕业季内容策划、升学咨询案例
- 决策因素：免费、开源、可商用模板

## 三、内容策略（痛点 → 成果 → 情感）

### 阶段 1：痛点唤醒（毕业季前 2 周）
**标题公式**：
- 「毕业季做蹭饭图，我花了 3 天 vs 5 分钟」
- 「Excel 做地图太丑？试试这个开源工具」
- 「班主任再也不用手动画地图了」

**内容结构**（小红书）：
1. 开头 3 秒：痛点截图（Excel 乱码、手动画的歪图）
2. 中段：5 分钟出图演示（GIF/短视频）
3. 结尾：真实案例 + 下载链接 + 话题标签

**话题标签**：
`#毕业季# #蹭饭图# #班级去向地图# #毕业墙# #班主任必备# #开源工具#`

### 阶段 2：成果展示（毕业季高峰期）
**标题公式**：
- 「我们班 47 人去向地图，3 小时出图」
- 「985 vs 普本，一眼看清全班未来」
- 「第一次做蹭饭图，学生哭了」

**内容结构**：
1. 成品图（高清大图）+ 导出设置
2. 数据洞察（「我们班 68% 去了 985/211」）
3. 制作过程（名单导入 → 自动布局 → 手动微调）
4. 学生/家长反馈

### 阶段 3：情感共鸣（暑期长尾）
**标题公式**：
- 「看见全班的未来，我突然懂了什么叫「毕业」」
- 「这张图，我保存了 3 年」

**内容结构**：
1. 老照片 + 新地图对比
2. 毕业 1/3/5 年后的去向更新
3. 「如果当年有这个工具…」

## 四、KOL 与种子用户策略

### Tier 1：头部教育/升学博主（10w+ 粉丝）
- 合作形式：免费提供定制模板 + 数据支持
- 预期产出：1 篇深度笔记 + 1 条视频
- 目标：3-5 位合作，带来种子流量

### Tier 2：班主任/年级组长（1w-10w 粉丝）
- 合作形式：优先支持 + 案例曝光
- 预期产出：真实使用截图 + 反馈
- 目标：20+ 位，产出 50+ 真实案例

### Tier 3：班委/学生会/设计爱好者（种子用户）
- 合作形式：开源贡献者 + UGC 征集
- 预期产出：作品分享 + 模板贡献
- 目标：100+ 位，产出 200+ 作品

### 激励机制
- 优秀作品上「案例墙」（官网/仓库）
- 贡献模板/字体/素材者署名 + 优先支持
- 毕业季「最佳班级地图」评选（小礼品 + 曝光）

## 五、UGC 裂变与私域沉淀

### 作品征集活动
**活动名**：「我的毕业去向地图」征集
**时间**：每年 6-7 月
**规则**：
- 上传真实班级地图（脱敏）
- 写 100 字制作故事
- 优秀作品进入「年度案例集」

**奖励**：
- Top 10：定制实体海报 + 署名
- Top 50：专属模板 + 优先功能支持
- 所有参与者：开源贡献者证书

### 私域沉淀
- 建立「蹭饭图用户群」（微信/QQ）
- 定期推送：新模板、功能更新、毕业季 checklist
- 收集需求 → 产品迭代闭环

## 七、风险与合规

### 数据隐私
- 所有示例数据必须脱敏（姓名缩写、去向模糊化）
- 用户上传的真实名单不入库，仅本地处理
- 导出图片默认不带敏感字段（可配置）

### 内容合规
- 禁止使用真实学生姓名 + 具体去向的组合
- 禁止宣称「升学率」「就业率」等敏感数据
- 所有合作 KOL 需签署内容授权协议

### 开源协议
- MIT License，允许商用但需保留署名
- 禁止将本项目用于商业 SaaS 服务（需单独授权）

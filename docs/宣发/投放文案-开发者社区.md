## 1. V2EX（节点：create 或 share）

**标题**：做了个毕业班去向地图编辑器（React + d3-geo），求导入和布局方面的意见

**正文**：

```
毕业季班主任要一张「我们班都去了哪」的地图，常见做法是 Excel 糊一张或手动画三天。

我做了个开源编辑器：导入 Excel/CSV → 按省/市聚合 → 卡片避让布局 → 导出 PNG/SVG/项目包。本地 IndexedDB，名单默认不出服务器。

技术栈：React 19 + Vite + TypeScript + MUI + d3-geo，内嵌 Node API（协作房间是内存态，约 30 分钟过期）。

现在最拿不准的三件事，求拍砖：
1. Excel 表头千奇百怪（姓名/学生/录取院校/城市混在一起），智能识别该做到哪一步就停、改让用户点选？
2. 60+ 人卡片在省级地图上怎么排，你们能接受「自动避让 + 少量手拖」还是必须分区钻取？
3. 国内用户如果不能接受 npm 安装，静态可打开的 Demo 最低要保留哪些功能（不要协作/不要 AI）？

仓库：REPO_GH
国内镜像：REPO_Gitee
意见请直接回这条或去 ISSUE_URL

不是来收 Star 的。你骂完导入流程，我这周能改。
```

**注意**：不要在标题写「神器」「颠覆」；发完 24 小时内盯评论。

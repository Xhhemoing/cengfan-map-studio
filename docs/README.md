## 维护规则

1. 用户能直接执行的步骤放在 README、USER_GUIDE 或 deployment 文档。
2. 产品优先级只在 `ROADMAP.md` 维护；历史规格保留为决策记录。
3. 临时代理输出、验证原始日志、缓存、机器绝对路径和本地密钥不进入仓库。
4. 新增文档时优先链接到本页；只有高频入口保留在仓库根目录。

## 截图后处理建议

1. 使用 `docs/示例数据/` 中的真实 CSV 导入，避免使用假数据
2. 截图后用系统自带「标记」工具轻微裁剪，去除多余边框
3. 成品图建议保留 1 张「带二维码」的版本（右下角或右上角放 GitHub 二维码）
4. 所有截图统一放入 `docs/宣发草稿/配图/` 目录

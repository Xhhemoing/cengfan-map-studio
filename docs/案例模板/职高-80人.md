# 案例模板：职高 / 中专（80 人）

## 基本信息
- **学校类型**：职业高中 / 中专
- **班级人数**：80 人
- **毕业年份**：2026
- **制作时长**：10 分钟（初稿，人数较多）

## 数据特征
- 去向以本省地级市与邻近工业城市为主（虚构）
- 卡片上写城市 + 企业类型即可，例如「苏州 · 数控车间」「杭州 · 护理实习」
- 对外只讲城市分布，不宣称就业率

## 制作流程
1. 导入名单：姓名、去向（城市或企业类型）、省份
2. 选择「紧凑卡片」或勾选紧凑布局
3. 智能布局；80 人优先保证不重叠、不越界
4. 按城市分组，避免同一市堆成一块
5. 上传校徽
6. 画幅改「展板 90×60cm」或 A2 后导出 PNG

## 推荐配置
- 卡片样式：紧凑 + 小字号（11–12）
- 颜色：学校工装色或深蓝 + 橙点缀
- 字体：系统默认
- 画幅：展板 90×60cm（约 100dpi）或 A2 横版
- 布局：城市分组 + 智能避让；重叠再手拖

## 班主任反馈
「人多不怕，先出能贴走廊的一张，家长只问孩子去了哪座城。」

## 衍生用途
- 实训楼走廊展板
- 家长会投影
- 开学季「师兄师姐在哪」对照图

---

**使用方法**：将此模板的流程套到蹭饭图 → 用脱敏名单替换 → 大班务必先紧凑布局 → 导出。禁止写就业率，不要提交真实姓名 + 单位。

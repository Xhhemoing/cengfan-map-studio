# 案例模板：国际部（12 人小班）

## 基本信息
- **学校类型**：国际部
- **班级人数**：12 人
- **毕业年份**：2026
- **制作时长**：2 小时（含世界地图切换）

## 数据特征
- 去向国家：美国、英国、德国、日本、新加坡（虚构示例）
- 海外去向用无锚点卡片展示，不宣称排名或录取率

## 制作流程
1. 导入名单 → 自动识别国家
2. 切换「世界地图」模板
3. 上传 5 国国旗 + 校徽
4. 手动微调卡片位置
5. 导出 3 种风格供投票

## 推荐配置
- 卡片样式：极简 + 国旗图标
- 颜色：国际范（深蓝 + 金）
- 字体：Arial + 学校字体
- 布局：世界地图 + 手动微调

## 衍生用途
- 国际部宣传册
- 留学咨询案例
- 校友录封面

---

**使用方法**：将此模板导入蹭饭图 → 替换示例数据 → 切换世界地图 → 导出 3 版

# 案例模板：国际部（12 人小班）

## 基本信息
- **学校类型**：国际部
- **班级人数**：12 人
- **毕业年份**：2026
- **制作时长**：2 小时（含海外去向卡片手动排布）

## 数据特征
- 去向国家：美国、英国、德国、日本、新加坡（全部为虚构示例）
- 海外去向在导入时标记「去向类型 = 海外去向」，不做省份锚定，以无锚点卡片形式排布在中国地图版式的留白区域

## 制作流程
1. 导入名单（表头：学生姓名 / 录取院校 / 城市 / 去向类型，海外去向填「海外去向」）
2. 选择极简模板
3. 上传国旗小图与校徽素材
4. 手动微调卡片位置（海外去向卡片集中排布在版面留白处）
5. 导出 3 种风格供投票

## 推荐配置
- 卡片样式：极简 + 国旗图标
- 颜色：国际范（深蓝 + 金）
- 字体：Arial + 学校字体
- 布局：中国地图版式 + 海外无锚点卡片手动排布

## 家长反馈
「家长群投票选出最有纪念意义的一版」

## 衍生用途
- 国际部毕业纪念册
- 校友录封面

---

**使用方法**：将此案例导入蹭饭图 → 替换示例数据 → 海外去向标记「去向类型 = 海外去向」→ 导出 3 版

# 蹭饭图 · 市场化与实用化

> **一句话**：编辑器已经能出图，但还停在「给会跑 `npm` 的人用的工作室」，不是「班主任今晚能交稿的工具」。  
> **日期**：2026-08-18 · **不替代** [宣发总流程](../宣发/国内互联网宣发总流程.md)。投放日历、渠道、KPI 仍只改那一份。  
> **收费边界**：支付、套餐、印刷生意不进本仓，见 [开源与收费边界](../开源与收费边界.md)。

---

## 1. 判断

市场化缺的不是文案，是**打开就能试**。实用化缺的不是功能数量，是**按班主任真实任务收口**。

班委手上通常只有一份微信群 Excel，要的是：导入 → 一张能发群、能送打印店的图。他们不会部署 8787，也不想学「展示框 / 安全边距 / 连接线样式」。

当前产品完成了工作室能力（五阶段、智能布局、模板、导出、本地存储），但漏斗在「看见成品之后」断开：国内用户打不开 Demo，开发者也不知道该拍哪一块。

---

## 2. 现状（对照真实任务）

| 班主任要做的事 | 现在 | 缺口 |
|----------------|------|------|
| 30 秒看到效果 | 必须 `git clone && npm install` | 没有可分享的 HTTPS 入口 |
| 3 分钟用自己的名单出图 | 导入 + 五阶段都在 | 专业面板同时铺开，主路径被冲淡 |
| 发班级群 / 朋友圈 | 有 1080 方图、竖版预设 | 工作台文案仍只讲毕业季 |
| 送打印店做展板 | 只有像素倍率 1×/2×/3× | 不会说「A3 / 90×60cm」 |
| 开学、校庆、同学会也做一张 | 引擎通用 | 没有场景包，淡季无话可讲 |
| 60 人以上大班 | 有紧凑卡片 | 默认仍按小班样张 |
| 把图交给下一任班委 | `.cengfan` 工程包 | 本机协作房间关进程即消失 |
| 相信「别人用过」 | 12 人虚构示例 | 没有脱敏真实案例 |

宣发侧 P0（Demo、Gitee、征求意见入口）见总流程 §0。仓库 description / topics 已补。GitHub Discussions 仍未开。

## 3. 市场化：先打开漏斗

用户主 CTA 必须是「打开就能试」，不能是 `git clone`。编辑器名单默认在浏览器本地，**静态托管前端即可当 Demo**，不必等 8787 + 备案做成完整服务器。AI / 协作可以没有；导入、排版、导出必须有。

| 优先级 | 做什么 | 完成标准 |
|--------|--------|----------|
| P0 | 静态 HTTPS Demo（Cloudflare Pages / GitHub Pages） | 手机微信能打开，点示例即可导出 |
| P0 | Gitee 公开镜像 | README 双链，国内 `git clone` 可用 |
| P0 | 用户群 / 开发者群分开 | 班主任不被技术讨论吓跑 |
| P1 | 开启 Discussions，置顶导入/布局/导出 | 意见有地方沉淀 |
| P1 | 种子班主任 5–10 人，收 1 份脱敏真案例 | 「成果」内容不再只靠虚构样张 |
| P2 | 应用内「反馈」打到同一 Issue 看板 | 试用后能留下一句槽点 |

部署步骤见 [静态 Demo](../deployment/static-demo.md)。没有 Demo 时，用户侧投放停在「评论扣 1 / 群文件示例包」，不要加大投放。

## 4. 实用化：按任务收口产品

### P0 · 印刷最后一公里

打印店要的是「A3 横版 / 90×60cm 展板」，不是「1500×1000 的 2× PNG」。

- 画布增加 A3 / A2 / 常见展板预设
- 导出旁用厘米 + dpi 说话，方便复制给打印店
- 示例项目导出前清掉水印越界、卡片遮挡，避免第一张宣发图带警告

本轮已落地：印刷预设 + 导出印刷提示。示例交付警告仍待单独修。

### P0 · 三分钟快速路径

五阶段适合精修，不适合第一次。默认应是：

```
导入名单 → 自动匹配 + 智能布局 → 导出
```

地图样式、展示框、内容精修延后出现。不理解术语的人应能在 10 分钟内交出一张能发的图。设计依据见 `frontUI2.md` §1.3，不要再加平行入口。

### P0 · 淡季场景包

现在是 8 月，毕业季已过。只讲毕业墙，内容违和。需要可一键套用的场景，而不是再做一套编辑器：

| 场景 | 默认画幅 | 默认文案倾向 |
|------|----------|--------------|
| 毕业去向 | A3 / 横版海报 | 去向分布，不写升学率 |
| 开学班级图 | 朋友圈方图 / 竖版 | 新班级第一张合影地图 |
| 校庆 / 同学会 | 横版海报 | 从哪来、现在在哪 |
| 社团活动 | 竖版 | 成员分布 |

工作台空状态已改为不只提毕业；完整场景包（标题、画幅、模板绑定）仍待做。

### P1 · 名单从微信来

真实名单往往是群文件、聊天记录、手机截图，不是干净的三列表格。

- 导入页置顶「下载 Excel 模板」
- 支持粘贴「姓名 学校 省份」文本
- 表头识别失败时用大白话说明缺哪一列，不要只报解析错误

### P1 · 大班默认紧凑

60 人以上自动改用紧凑卡片与更小字号，避免第一眼全是重叠。极端密集以「人在图上、不越界」为先，美观其次。

### P2 · 交付与复用

- PDF（打印店比 SVG 好收）
- 工程包跨设备说明做成工作台上的一句人话，而不是只写在用户指南
- 本机协作房间过期规则写进界面；不要让班委以为「房间码能留到毕业典礼」

## 5. 明确不做

- 开源仓里做支付、套餐、模板结算
- 做成印刷厂或学校统付生意
- 对外宣称升学率、就业率、录取率
- 用真实姓名 + 去向做截图或文案
- 把 AI 当主路径；AI 只能预览、白名单、确认后应用
- 再写一份和宣发总流程打架的投放计划

## 7. 验收

- **市场化**：微信里能打开 Demo，用示例名单导出一张图；国内能从 Gitee 克隆。
- **实用化**：新建项目可选 A3 展板；导出区能读到厘米尺寸；文科/职高案例模板能通过 `npm run promo:check`。
- **回滚**：还原本文、印刷预设与案例模板即可；不改工程包格式，旧项目仍按像素画布打开。

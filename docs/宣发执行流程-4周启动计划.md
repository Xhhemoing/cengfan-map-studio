# 蹭饭图宣发执行流程 — 毕业高峰 4 周（仅 5–7 月）

> **2026-08-15 起不要当周执行本文。** 当前是淡季，请改走  
> [docs/宣发/国内互联网宣发总流程.md](宣发/国内互联网宣发总流程.md) 的 **8 周蓄水计划**。  
> 本文只在 **每年 5–7 月毕业高峰** 启用；执行前仍须满足总流程 P0（HTTPS Demo、Gitee、Issue 模板）。

历史目标（高峰季）：4 周内基础闭环。淡季 KPI 以总流程 §7 为准，不要用「Star ≥ 300」考核 8 月。

**复盘**：每周日 20:00。命令：`npm run promo:check` / `promo:content` / `promo:report`。

## Phase 1：痛点唤醒周（Week 1）

### Day 1（周一）：小红书首发（痛点类）
**平台**：小红书  
**内容**：从草稿中选 2 篇痛点笔记  
**发布时间**：上午 9:00 / 晚上 20:00  
**话题标签**：`#毕业季 #蹭饭图 #班级去向地图 #毕业墙 #班主任必备 #开源工具`

**预期**：阅读 3000+，收藏 80+，评论 20+

### Day 2（周二）：B站教程视频上线
**平台**：B站  
**内容**：5-8 分钟「Excel 做毕业地图太丑？3 分钟出图教程」  
**脚本**：`docs/宣发草稿/B站-教程-2026-08-14.md`  
**发布时间**：晚上 19:00

**预期**：播放 500+，点赞 50+，收藏 30+

### Day 3（周三）：抖音 15 秒快闪
**平台**：抖音 / 视频号  
**内容**：痛点脚本版本 A（Excel 乱码 + 手动画歪图）  
**脚本**：`docs/脚本库/痛点-3版.md`  
**发布时间**：上午 11:00

**预期**：播放 2000+，点赞 150+

### Day 4（周四）：GitHub 冷启动
- 在 3 个相关仓库 Issue 下留言（搜索关键词：毕业地图、班级去向、毕业墙）
- 在「前端」「React」「教育」相关 Discord/微信群发项目介绍
- Star 目标：50

### Day 5（周五）：需求收集帖
**平台**：小红书  
**内容**：痛点类第 3 篇 + 投票「你最希望蹭饭图支持什么功能？」
**话题**：`#毕业季 #蹭饭图 #功能建议`

### Day 6-7（周末）：数据收集 + 复盘
```bash
/宣发 收集数据
/宣发 生成报告 --周期 周
```
**输出**：`docs/宣发复盘/复盘报告-2026-08-XX.md`

**复盘会议**（30 分钟）：
- 本周阅读/播放/Star 完成率
- 哪篇内容互动最高？为什么？
- 下周是否切换「成果展示」阶段？

**里程碑**：小红书粉丝 ≥ 200，GitHub Star ≥ 80，B站播放 ≥ 800

## 风险与应急

| 风险 | 应急方案 |
|------|----------|
| 小红书笔记被限流 | 立即换账号发布，或改成「合集」形式 |
| KOL 无回复 | 降低粉丝门槛，增加 Tier 3 数量 |
| UGC 投稿为 0 | 内部先做 3 个案例 → 激励种子用户投稿 |
| GitHub Star 增长慢 | 在更多前端/教育相关 Issue 下留言 |

## 0.2.0：左右栏信息架构

规格已锁定；左栏回答「进度 / 下一步 / AI」，右栏回答「选中了什么、能改什么」。见 [设计规格](superpowers/specs/2026-08-26-left-right-rail-ia.md) 与 [任务拆分](superpowers/plans/2026-08-26-left-right-rail-ia.md)。顺序为 P0 右栏减噪 → P1 左栏分栏 → P2 摘要搬迁 → P3 收尾。

开工前收集至少 5 条真实用户反馈，以反馈验证优先级；每阶段实际走查「工作台 → 导入 → 导出 PNG」。不恢复「一键智能排版」，不改 ProjectDocument，不放宽文件大小棘轮或 MapInspector 默认展开契约。

## 0.3.0：能力项

印刷出血接线、首屏包体积优化、A2 高分辨率低内存验证、协作重连与降级可见性、SVG 文字转曲继续作为候选。已有工具函数不等于已经接入主流程；已有文件快照不等于账号级或多实例持久协作。具体日期不在没有验证依据时承诺。

## 不做与维护纪律

不引入支付、套餐、收费结算；见 [开源与收费边界](开源与收费边界.md)。不为压低告警修改默认构图或名单事实，不把本地编辑器改为必须登录/联网，也不整支恢复被淘汰的大型历史分支。

所有 PR 基于 `main`；开放 PR 尽量控制在 2–3 个，先收口再扩张。分支超过 7 天应复核负责人和独有提交，不能按年龄盲删。合并之后清理已合入且未移动的分支。正式发布仅从审查过的主干 SHA 产生 tag，禁止重写已发布 tag；主干 Pages 是开发预览，Release 后显式部署对应 tag。流程见 [RELEASING](RELEASING.md)。

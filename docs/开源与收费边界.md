## 1. 为什么改 AGPL

编辑器会以网页形式提供给班委使用。AGPL 要求：若有人**修改**本程序并作为网络服务提供给他人，必须向使用者提供对应源码。这挡的是「改一改做成闭源托管去卖」，不是禁止你自己以后收费。

AGPL 仍然允许：自用、修改、分发、对副本收费。它不允许：拿改过的版本做公开托管，却不给源码。

此前文档里「MIT 允许商用，同时禁止商业 SaaS」与 MIT 文本冲突，已作废。

以前按 MIT 拿到的旧副本，对当时的接收者仍按 MIT。**本版本起**以 AGPL-3.0-only 为准。若仓库里已有外部贡献者的代码，合入前须确认对方同意按 AGPL 再分发。

## 2. 收费只做「班级自己掏」的事

出图是**每个班自己的行为**，学校不会统一批软件经费。因此：

| 做 | 不做 |
|----|------|
| 社区模板的手续费（班委/作者自愿） | 向学校申请统付、年级打包授权 |
| 以后：云端便利、AI 额度等班费/个人付 | 印刷厂业务、官方印刷套餐 |
| 核心导入 / 布局 / 导出保持可自建 | 把导出按钮做成开源仓里的付费锁 |

用户把 PNG/SVG 拿去自己打印，那是他们的事，产品不做成印刷服务。

**现在（产品未定型）**：开源仓只把编辑器做稳。不接支付、不上套餐后台。

**定型之后**：在**本地私有目录**开发收费，再视需要单独开私有仓，不把支付代码推进本仓库。

---

## 3. 社区模板手续费（以后的本地层）

开源仓可以有：模板文件格式、内置/示例模板、贡献模板的文档。这些跟程序走 AGPL，班委自建时免费用。

「社区模板手续费」指以后在本地商业层做的事，例如：作者上架一份模板、使用方付一笔小手续费、平台抽成。那是**资源与撮合**，不是给 AGPL 程序本身加许可费（AGPL 禁止用许可费限制用户按协议使用程序）。

未定型前不要在 Issue 里做支付方案，也不要在本仓加微信/支付宝 SDK。

---

## 4. 收费代码放哪（强制）

支付、套餐、订单、兑换码、模板手续费结算：**不准出现在本 Git 仓库。**

推荐放在仓库**外面**的私有目录，例如：

```
E:\Project\蹭饭图\          ← 本开源仓（可推 GitHub / Gitee）
E:\Project\蹭饭图-收费\     ← 仅本机或私有仓，永不 push 到开源远端
```

若暂时放在开源仓旁边的隐藏目录，必须被 `.gitignore` 挡住：

```
.local-commercial/
.local-billing/
```

Agent 与贡献者：发现 `微信支付`、`预支付`、`sku`、`套餐价格` 等实现要进 PR，直接拒绝并指向本文。

本仓允许写的只有本文这种**政策**，以及开源编辑器本身。对接方式以后用私有仓、或本机 path 引用，不要把密钥和商户号写进 `.env.example`。

## 5. 对外怎么说（一句）

> 蹭饭图编辑器按 AGPL-3.0 开源，你可以自己部署、名单默认在本地。社区模板若以后收取手续费，由班级自己支付；不做学校统付，也不做印刷生意。支付与套餐不在这个开源仓库里。

开发者文案不要再写「MIT、可商用包装成闭源 SaaS」。改过再托管，需要按 AGPL 开放对应源码。

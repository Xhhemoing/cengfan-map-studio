## 下载与运行

`cengfan-map-studio-v0.1.3-web.zip` / `.tar.gz` 是根路径 `/` 的静态站，需 HTTP/HTTPS 托管，不包含 Node API。`BUILD_INFO.json` 记录源码 commit 和验证运行；下载全部附件后可用 `sha256sum -c SHA256SUMS.txt` 核对。

需要完整服务或子路径构建时使用 tag 的源码：Node 22.13+（22.x）、npm 10+，执行 `npm ci`。静态构建设置 `VITE_PUBLIC_DEMO=1` 和对应 `BASE_PATH`；完整部署先看 [部署指南](https://github.com/Xhhemoing/cengfan-map-studio/blob/v0.1.3/DEPLOY-SERVER.md)。

# 蹭饭图 — 毕业班去向地图编辑器

> **让毕业季的「我们班都去了哪里」不再是 Excel 乱码或手动画的歪图。**

---

## 为什么选择蹭饭图？

### 场景 1：班主任/年级组要做「毕业去向墙」
**痛点**：Excel 导出的表格丑、看不清；手动画地图要画 3-5 天；学生名单改了还要重画。

**蹭饭图的答案**：
- 导入 Excel/CSV 名单 → 3 分钟出初稿
- 智能布局自动避让，卡片不重叠
- 支持手动微调 + 实时预览
- 一键导出高清 PNG/PDF，毕业典礼直接用

### 场景 2：班委/设计组要做「班级毕业地图」
**痛点**：想让地图好看，但调样式、排版、字体太耗时；想加校徽、贴图但不会 PS。

**蹭饭图的答案**：
- 内置 10+ 卡片模板 + 自定义样式
- 上传字体、贴图、校徽，按省份绑定
- 素材库一键应用，实时看到效果
- 支持导出项目包，下次直接复用

### 场景 3：毕业生/家长想「纪念全班的未来」
**痛点**：想知道「我们班 985 去了多少人」「谁和谁去了同一个城市」，但没人做这张图。

**蹭饭图的答案**：
- 自动统计升学/就业分布
- 按省份/城市聚合展示
- 导出后可发朋友圈、做成实体海报
- 支持「毕业 N 年后更新」——把去向改成真实去向，保存回忆

### 场景 4：教育博主/升学咨询想「做毕业季内容」
**痛点**：需要真实案例、工具推荐，但市面上没有开源、免费、可商用的毕业地图工具。

**蹭饭图的答案**：
- MIT 开源，允许商用（需署名）
- 提供标准案例模板 + 数据脱敏指南
- 支持 KOL 合作 + UGC 征集
- 建立「年度最佳班级地图」评选活动

## 技术栈与架构

- **前端**: React 19 + Vite + TypeScript + MUI + d3-geo
- **后端**: Node.js 内嵌 API（认证、协作、AI 助手）
- **测试**: Vitest + jsdom
- **数据**: 静态省/市数据（`src/data/china-locations.ts`）

详见 [AGENTS.md](AGENTS.md) 与源码。

## 许可证与合规

- **开源协议**: MIT License（允许商用，需署名）
- **数据隐私**: 所有示例数据脱敏；用户上传的真实名单仅本地处理，不入库
- **内容合规**: 禁止使用真实姓名 + 具体去向的组合；禁止宣称「升学率」等敏感数据

完整合规条款见 [宣发政策文档](docs/宣发政策-小红书与社交平台.md#七风险与合规)。

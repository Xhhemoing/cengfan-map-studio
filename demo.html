⚡ 3 分钟出图

导入 Excel/CSV → 自动匹配省份 → 智能布局 → 一键导出高清 PNG/SVG。班主任再也不用熬夜手动画地图。

🎨 个性化定制

上传校徽、字体、贴图，按省份绑定。10+ 卡片模板一键切换，真实案例可复用。

🤝 协作编辑

创建房间邀请班委分工，实时同步。支持「仅查看」和「可编辑」邀请码。

📦 开源免费

开发者快速开始

# 1. 克隆仓库
git clone https://github.com/Xhhemoing/cengfan-map-studio.git
cd cengfan-map-studio

# 2. 安装依赖
npm install

# 3. 启动开发服务器（前端 5173 + API 8787）
npm run dev

# 4. 生产构建
npm run build
npm run start

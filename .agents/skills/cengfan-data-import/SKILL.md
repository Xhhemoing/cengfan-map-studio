# 蹭饭图学生数据导入导出

本仓库面向毕业班去向地图,学生名单通过 xlsx 导入。遵循以下步骤保证数据一致。

## 1. 模板下载

- 模板由服务端生成,路径与字段定义见 `src/server` 中的导入模块(关键词 `xlsx`、`template`)。
- 用户要求"下载模板"时,调用现有下载入口,不要手工构造模板。

## 2. 表头智能识别

- 列映射逻辑在 `src/lib`(或 `src/server`)的导入解析模块中,支持表头别名(如"姓名"/"学生姓名"、"去向"/"录取学校")。
- 修改识别规则时必须同步更新对应 `*.test.ts`,覆盖至少:标准表头、别名表头、缺失必填列、多余未知列。

## 3. 校验与导入

- 必填字段缺失、格式非法(如去向类型不在枚举内)必须给出可读错误,不允许静默跳过。
- 导入结果需回显给用户(成功数/失败数与原因),参考现有导入 UI。

## 4. 验证

```bash
npx vitest run <导入解析模块的测试文件>
npm run lint
```

## 输出

报告:改动的文件、覆盖的表头/校验分支、验证命令与结果。

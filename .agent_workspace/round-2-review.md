### R2-5 SSE backpressure — ACCEPT
- `server/index.ts:writeStream` (896-990): per-subscriber unflushed bytes metered via write-completion callbacks (the only reliable release signal — noted in-code), soft threshold at cap/2 pauses droppable events (heartbeats, members, ops-only/self snapshots — clients recover via T2's contiguity gate + backfill), hard cap (default 2MiB, injectable) disconnects the laggard with `response.destroy()` to actually reclaim queued memory. `teardownStream` settles all pending write callbacks so the global counter can't leak; the `settled` flag prevents double-subtraction when destroyed sockets later fire callbacks.

Disconnect → reconnect → fresh bootstrap is the only safe convergence. (The lite path remains in use where it is safe: ops-carrying events and self-echoes.)
- Bootstrap frame is exempt from the per-event cap (else big rooms reconnect-loop forever) but counts toward backlog; the heartbeat doubles as the reaper for backlogged-but-quiet streams. Heartbeat-write-failure timer leak fixed (streamTornDown check before `setInterval`, 1051-1055).
- `roomStreamStats()` exposes buffered/peak/disconnect/dropped counters; the 50-never-draining-subscribers test asserts the memory bound, plus pause-before-disconnect and per-event-cap tests.
